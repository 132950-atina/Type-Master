#Type Master

Type Master is a hacker themed typing speed game built with HTML, CSS, and JavaScript.

## About the Game

Improve your typing speed and accuracy while racing against the clock in a cyber-style terminal environment.

Players must type the displayed text as quickly and accurately as possible before the timer reaches zero.

# Features

- Hacker themed interface
- Boot sequence animation
- Live typing validation
- Progress bar
- WPM calculation
- Accuracy tracking
- High score saving
- Background music
- Win and lose sound effects
- Anti cheat protection (copy, paste, cut, and right click disabled)

##Built With

- HTML5
- CSS3
- JavaScript
